## .gitignore
**/.terraform/* - будут игнорироваться все файлы внутри каталога с именем .terraform, на любом уровне вложенности.
*.tfstate - будут игнорироваться все файлы, имя которых заканчивается на .tfstate.
*.tfstate.* - будут игнорироваться все файлы, в имени которых есть .tfstate, после которой сразу идёт точка и любые символы.
crash.log - будет игнорироваться файл с именем crash.log.
crash.*.log - будут игнорироваться все файлы, имя которых начинается с crash., дальше идут любые символы, и заканчивается на .log.
*.tfvars - будут игнорироваться все файлы, имя которых заканчивается на .tfvars.
*.tfvars.json - будут игнорироваться все файлы, имя которых заканчивается на .tfvars.json.
override.tf - будет игнорироваться файл с именем override.tf.
override.tf.json - будет игнорироваться файл с именем override.tf.json.
*_override.tf - будут игнорироваться все файлы, имя которых заканчивается на _override.tf.
*_override.tf.json - будут игнорироваться все файлы, имя которых заканчивается на _override.tf.json.
*tfplan* - будут игнорироваться все файлы, в имени которых есть буквосочетание tfplan.
.terraformrc - будет игнорироваться файл с именем .terraformrc.
terraform.rc - будет игнорироваться файл с именем terraform.rc.
